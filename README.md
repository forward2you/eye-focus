# Eye Focus

参考实体设备照片和视频制作的绿点跟随网页：绿色面板铺满浏览器，保留 33 个金属定位点和发光绿点，不绘制设备外框。点阵随窗口尺寸重新布局，圆点不会拉伸。没有时长、点数、大小等设置，没有账号、追踪服务、第三方字体或外部依赖。

背景采用低饱和深绿色，定位点降低对比度；目标主体直径为 20 个 CSS 像素，外围采用柔和光晕，不使用白色亮芯。网页配色无法控制显示器的实际亮度，也不能保证消除视觉不适。

这是外观和视觉目标运动演示，不是医疗设备，不能用于诊断、治疗近视或替代专业调节训练。固定距离屏幕上的光点运动不会产生真实的远近调焦变化。视频只展示部分点亮规律，以下完整流程是据此设计的演示，不代表原设备程序，也不是医疗训练处方。

## 固定两分钟流程

| 有效运行时间 | 点数 | 位置与动作 |
|---|---|---|
| 0–20 秒 | 1 | 中排，从中央向右逐格到边缘，再向左逐格往返 |
| 20–40 秒 | 1 | 上排，重复单点往返 |
| 40–60 秒 | 1 | 下排，重复单点往返 |
| 60–80 秒 | 2 | 中排，左右对称逐格展开、合拢 |
| 80–100 秒 | 2 | 上排，重复双点展开、合拢 |
| 100–120 秒 | 2 | 下排，重复双点展开、合拢 |
| 120 秒 | 0 | 熄灭目标，自动结束，不自动重播 |

单点每 1.25 秒切换一个节点。双点每约 1.11 秒切换一组节点，每排完成三次展开、合拢，双点阶段始终保留两个不同位置的目标，不重合为一个点。按节点直接切换，不采用平滑滑动、闪烁或逐渐加速。

## 使用

- 点击“开始跟随”，运行固定两分钟流程；底部显示本轮剩余时间和单点 / 双点阶段。
- 暂停、离开页面期间不计时；继续时保留进度。满 60 秒自动切换双点，满 120 秒自动结束；点击“再来一次”从单点与 02:00 重新开始。
- 点击“暂停”或按空格键（焦点不在按钮上时）暂停、继续；Esc 暂停。
- 支持时可点击“全屏”。切换页面、窗口、显示区域或全屏状态时自动暂停，需手动继续。
- 保持自然眨眼；如有眼痛、头晕或复视，立即停止。儿童应在成人监督下使用；需要治疗时先咨询专业人员。
- 页面不采集或保存个人信息、练习记录，也不检测视线。

## 部署到 GitHub Pages

不需要购买域名、配置 DNS 或管理证书。

1. 在 GitHub 创建仓库，例如 `eye-focus`，将本项目文件上传到 `main` 分支根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment → Source** 选择 **GitHub Actions**。
4. 推送到 `main`，或在 **Actions → Test and deploy GitHub Pages → Run workflow** 手动触发。
5. 工作流会先检查 JavaScript、运行弹球运动测试，通过后自动发布。
6. 等待部署完成，访问 `https://你的用户名.github.io/eye-focus/`；实际地址以 Pages 设置页显示为准。

GitHub Pages 提供 `github.io` 地址与 HTTPS。无需填写 Custom domain。所有资源使用相对路径，支持仓库子路径部署。是否可用取决于仓库可见性与 GitHub 套餐；公开仓库通常最方便。

点阵版地址为站点根路径，弹球版地址为 `https://你的用户名.github.io/eye-focus/bounce/`。工作流仅上传网页资源，不上传测试或仓库文件。无需 npm 安装或前端打包。

发布时会将弹球页面的样式、主脚本和运动模块 URL 统一加上当前提交版本，避免浏览器将不同发布版本的模块缓存混用。本地预览使用固定占位版本即可，无需生成文件。资源加载失败时会明确提示并禁用播放按钮，不会留下可以点击但无响应的空白画布。

## 弹球版

独立页面位于 [bounce/](./bounce/)，不改变点阵版的运动模式：

- 深绿色背景铺满窗口，没有设备边框或定位点阵。
- 球体主体直径 24 个 CSS 像素，柔和光晕，不闪烁。
- 以 240 个 CSS 像素 / 秒的恒定速度运动。初始方向随机，之后像台球一样等角反射，不再随机偏转或加速。
- 球体接触浏览器可视区边缘后才反弹，不为工具栏预留隐形碰撞边界；边缘处的外围光晕可能自然裁切，球体不会越界。全屏时使用整个显示区域。
- 显示最近 1.8 秒的渐隐运动尾迹，保留准确的反弹折点。暂停时尾迹一并冻结；调整窗口或重新开始会清除旧尾迹。
- 前 60 秒为单球，第 60 秒增加第二个独立运动的球，第 120 秒熄灭并停止。球只与边界反弹，彼此不碰撞。
- 暂停不计时；切换窗口、后台、全屏或调整显示区域会暂停；需手动继续。
- 随机运动不代表医疗效果更好，也不应强迫自己同时追踪两个球。出现头疼、眼痛、复视时立即停止。

## 验证

无需安装依赖，有 Node.js 22 或更新版本即可运行：

```sh
node --test tests/bounce.test.mjs
```

## 本地预览

可直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8080`。
